Instalar DK Cliente no telemóvel

Toque no botão abaixo para instalar. Depois use o ícone DK no ecrã inicial.

Instalação manual (se o botão não aparecer)

Android: Chrome → menu ⋮ → «Instalar app» ou «Adicionar ao ecrã inicial».

iPhone: Safari → partilhar ↑ → «Adicionar à Tela de Início».

Use o Chrome ou Safari (não o browser dentro do WhatsApp).

Informe CPF e senha. A senha inicial é 123456; no primeiro acesso o app pede uma nova senha de 6 números.

Com o app instalado no ecrã inicial (Android), no banco use Partilhar o comprovante e escolha DK Cliente na lista — o ficheiro vai para «Enviar comprovante».
