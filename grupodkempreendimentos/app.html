Clique no botão abaixo ou use a instalação manual (Windows, Android ou iPhone).

Instalação manual

Windows (PC): Chrome ou Edge → ícone «Instalar» (⊕) na barra de endereço, ou menu ⋮ → «Instalar Grupo DK» / «Aplicativos» → «Instalar este site como aplicativo».

Android: Chrome → menu ⋮ → «Instalar app» ou «Adicionar ao ecrã inicial».

iPhone: Safari → partilhar ↑ → «Adicionar à Tela de Início».

Não use o browser dentro do WhatsApp — abra no Chrome, Edge ou Safari.
